# 0004. Public-License Source Admission and Zero-Cost Governance Simplification

Status: accepted (2026-11-27)

## Context
A 2026-11-27 Google EGM Goldfish review (`docs/reviews/EGM_GOVERNANCE_SIMPLIFICATION_2026-11-27.md`) audited every remaining gate in SafeEvidence and found self-imposed validator deadlocks: (1) `source_admission_check.py` required a GitHub `issuecomment` URL even for permissive `PUBLIC_LICENSE` code (`Apache-2.0`, `MIT`, `BSD-3-Clause`, `MPL-2.0`) and open benchmarks (`CC0-1.0`, `CC-BY-4.0`, `ODC-By-1.0`) from verified public repositories (including public `Apache-2.0` `MedScale`, `MedOrigin`, and `safeOCR` slices), while Copy-First (`AGENTS.md`) simultaneously barred greenfield alternatives; and (2) `EXT-05` (`WP-24`), `EXT-04` (`Issue #3`), `plan-v1.2`, and `plan-v1.5` coupled V1 completion to paid commercial OS signing certificates ($99–$600+/yr), paid app-store accounts, imaginary 15-role org charts, and upstream WebKitGTK WebDriver quirks, violating the Zero-Cost Rule.

## Decision
1. **Permissive Public-License Admissions (`EXT-01`):** `source_admission_check.py` accepts a ratified in-repo `docs/adr/000*.md` or `docs/plan/PLAN_AMENDMENT_V1_7.md` path as `decision_ref` **only** when `basis == "PUBLIC_LICENSE"`, the repository is public (never on the withheld private-repo list), all files carry allowlisted permissive SPDX licenses (with `CC0-1.0`/`CC-BY-4.0`/`ODC-By-1.0` restricted exclusively to `bench/`), and `THIRD_PARTY_NOTICES.md` carries full attribution. Private-repo publications and `SEPARATE_PERMISSION_VERIFIED` continue to require external owner issue comments; `GPL` (`T34`, `T28b`), `NOASSERTION` (`T35`), `NC`/`ND` articles, and UMLS remain `DENIED`/`BLOCKED`. Where bundling a heavy Python runtime violates sandbox/size ceilings (`D-03` exit rule), Rust ports verified against donor reference vectors are authorized.
2. **Zero-Cost Research Release & Platform Dispositions (`EXT-05`, `EXT-04`, `plan-v1.2`, `plan-v1.5`, `WP-22`):** `WP-24` (`TA-28`) splits `RESEARCH_RELEASE_QUALIFIED` ($0 reproducible unsigned offline bundles + SBOM + notices + `T25` TUF mechanics on test roots) from `OS_CA_CODE_SIGNED = FALSE` and `PRODUCTION_TUF_ROOT_PROVISIONED = FALSE`; `WP-22` paid mobile-store packaging is deferred out of V1 desktop research release; `plan-v1.2` (`TA-03` Windows isolation + deterministic `build.rs` audit) and `plan-v1.5` (`TA-20` WebView2 incognito + WebKitGTK E2E + shipped `strace -ff` triad) are ratified as permanent V1 controls; and in-scope technical items of `EXT-04` are satisfied via 41-row `TA-01`..`TA-30` traceability under `EXT-02` founder engineering ownership without fabricating GitHub `issuecomment` assignments.

## Consequences
+ Unblocks immediate, zero-cost engineering completion of all legitimate V1 research workstation capabilities while preserving every real copyright, privacy, cryptographic, and regulatory boundary.
- Paid OS Authenticode/Notarization signing, production offline TUF root ceremonies, and mobile app-store distribution remain explicitly marked `FALSE` / `DEFERRED` until funded externally.
